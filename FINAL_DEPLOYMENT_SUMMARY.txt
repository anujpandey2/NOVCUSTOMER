DURING EXECUTION:

    "    Status: Submitted (job ID: ...)"
    "    Status: Running (5s elapsed)"
    "    Status: Running (10s elapsed)"
    "    Status: Completed (45s elapsed)"

  Job status values:
    - Submitted  : Job received, queued
    - Running    : Currently executing
    - Completed  : Success
    - Failed     : Error during execution
    - Aborted    : Cancelled by user or system

COMMON ISSUES:

  1. Authentication fails
     Fix: Run "az login" and ensure Power BI is enabled
  
  2. Workspace not accessible
     Fix: Verify workspace ID and user permissions
  
  3. Notebook timeout (10+ minutes with no progress)
     Fix: Check Fabric capacity availability, increase SKU
  
  4. Lakehouse creation fails (409 Conflict)
     Fix: Script reuses existing lakehouse, safe to ignore
  
  5. Notebook execution fails
     Fix: Check notebook cell error messages in Fabric workspace
  
  6. Rate limit exceeded (429 Too Many Requests)
     Fix: Automatic retry with exponential backoff applied
